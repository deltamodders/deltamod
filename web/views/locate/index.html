Locate your game

To use Deltamod, you need to locate your game installation. But don't worry! It's very easy.

Beginning from Deltamod 1.9, Deltamod no longer copies your game to its app data by default. As such, no second copy of your game is created when importing.

Please make sure the game is in a directory which is always available, or tick the box to override this behavior.

gamepad_up Select the game you are trying to add.

folder Select the folder where your game is installed.
